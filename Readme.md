# I'm just a little guy

'I'm just a little guy' is a game I originally started for a game jam...But since I was quite lazy to finish it , I decided to shubmit it to Expedition Ireland, another Hack Club program !

# What does it do ?

Well it's a video game... More seriously, it's a platformer ; you're playing a little guy who just want to go home...But the road have quite change...

For now there's one level, but I know I'll add other level too.*

# What did I use ?

Oof, a lot of things actually !

- **Godot** to make the game : it's an open source game engine. I've also use it to make the background in the first version of the game, but that's actually a bad idea, it may be too heavy and may cause your game to be quite slow ! ( That's why I've delated half of my game when it was almost finished *sob*). But that's also where I've coded the game.

- **Pxlated** to make *most* of the asset of the game : Most people use Aesprite ( but I don't have the moneyyyy) or Libresprite ( but I had soo much difficulty making Tileset because I was *beginner*, but I did use it for making the player). So I've found **Pxlated** accidentaly on itch.io, they have an integrated tileset tool ! So does Aesprite is I remember correctly...

- **Itch.io** to import the sfx sound : As you may (not) know, I'm not a sound artist lol, so I've used free sfx sound on itch.io, here are the link and credits :

- **Youtube** to learn most of the things I've added : Moving platform, main menu, how to add a background, etc..

- **Acrylic Marker** to draw the obstacle : I've draw a few obstacle such a branch and rocks by hand using those, because at first I wanted to make a videogame with hand draw asset, but I've changed a little bit of my DA.. ( direction artistique = artistic direction).

- **Ibis Paint (on pc)** to remove the background of the drawings : everything is in the previous sentence. Though you should know Ibis Paint on PC isn't really free ; you only have one hour free per day (yeaaaaah....)

# Dependencies

To run this project on your device, well you need a few things :

- **Godot**, especially the *( 4.7) version*
- **A laptop** : it may sound dumb, but as far as I know, I don't think you can dowlad this app on a phone devicies.
- **And pastience** : you'll need it.
- **A pixel art software** : only if you want to modify what I've already did. Though I'm not sure that the files from *Pxlated (the web version)* will work on Aesprite or Libresprite..
# Installation

- First you'll need to dowload the project on your laptop.
- Then open Godot and click on Import, and select the download file, it should open the project automatically
- Et voilà ! You got my game on your laptop.
